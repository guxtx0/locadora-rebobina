# Base original (TMDB 5000)

O pipeline usa dois arquivos da base pública **TMDB 5000 Movie Dataset**:

- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

Baixe em https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata e coloque os dois arquivos nesta pasta.

Os arquivos não vão para o repositório (estão no `.gitignore`) porque são grandes e pertencem à base original.
